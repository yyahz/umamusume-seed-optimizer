# 闪耀优俊少女 · 种马优选器

一个嵌入“吗哩吗哩工具箱”的 Chrome / Edge Manifest V3 扩展，用角色、因子星级和优先级筛选好友种马，并按综合匹配度排序。

> [!IMPORTANT]
> 使用前必须在[吗哩吗哩工具箱](https://game.bilibili.com/tool/pd)手动完成 B 站登录。本扩展不会代填账号、密码或验证码，也不提供绕过登录的能力。

> [!NOTE]
> 这是非官方社区项目。B 站页面或接口更新后，扩展可能需要同步适配；请遵守游戏及网站的服务条款。

## 功能

- 按名称和初始星级检索、多选角色；不选角色时搜索全部角色。
- 任意拖动蓝、红、绿、白四类因子，设置颜色间优先顺序。
- 白因子独立拆分为剧本、技能、比赛三个目录，并支持名称检索和分批展开。
- 每个具体因子同时设置家系合计 `1–9★`、本体最低 `1–3★` 和 P1 / P2 / P3 优先级。
- 将新因子默认放入 P1；可拖动紧凑因子行或使用下拉框调整优先级，再次点击目录中的同一因子即可取消。
- 合并默认推荐池、高优先级组合与单因子候选，去重后按综合匹配度从高到低展示。
- 可调搜索深度，并可过滤关注人数已满的玩家。

## 安装

### 准备工作

- Chrome 或 Microsoft Edge 的较新版本。
- 本仓库完整目录；不要只下载某一个 JavaScript 文件。
- 可正常访问吗哩吗哩工具箱的 B 站账号。

### Chrome

1. 打开 `chrome://extensions`。
2. 打开页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本仓库根目录，也就是包含 `manifest.json` 的目录。
5. 打开[吗哩吗哩工具箱](https://game.bilibili.com/tool/pd)，手动登录后刷新页面。
6. 点击页面右下角的“种马优选器”。

### Edge

1. 打开 `edge://extensions`。
2. 打开左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本仓库根目录，也就是包含 `manifest.json` 的目录。
5. 打开[吗哩吗哩工具箱](https://game.bilibili.com/tool/pd)，手动登录后刷新页面。
6. 点击页面右下角的“种马优选器”。

如果没有看到“加载已解压”按钮，请先确认开发者模式已经打开；浏览器受学校或公司策略管理时，该功能也可能被管理员禁用。

## 使用

1. 在“选择角色”中检索并多选目标角色；保留为空会搜索全部角色。
2. 拖动蓝、红、绿、白因子卡片，确定四种颜色的整体优先顺序。
3. 切换颜色及白因子子类，在目录中搜索并点击所需因子。
4. 为每个已选因子分别设置家系合计星级、本体最低星级和 P1 / P2 / P3。
5. 选择搜索页数及是否过滤满关注玩家，然后开始搜索。
6. 根据总分、各颜色达标数和因子门槛提示比较结果。

颜色顺序权重为 `8 / 4 / 2 / 1`，颜色内部 P1 / P2 / P3 权重为 `9 / 3 / 1`。每种颜色会先单独归一化，避免大量低优先因子仅凭数量压过高优先颜色。家系合计与本体星级必须同时达到设置值才算完全达标；综合分仅表示当前偏好下的相对顺序，不代表游戏内继承概率或养成收益。

## 隐私与安全边界

- 扩展只在 `https://game.bilibili.com/tool/pd*` 页面运行，并向 `https://api.game.bilibili.com/*` 发出查询请求。
- 请求复用浏览器中已有的 B 站登录会话；扩展不会读取、保存、显示或导出 Cookie，也不会要求用户粘贴 Cookie。
- `chrome.storage.local` 仅保存角色 ID、因子选择与星级、颜色与 P 级顺序、搜索深度以及满关注过滤选项，方便下次打开时恢复偏好。
- 因子目录、角色目录和好友种马搜索均为只读用途；扩展不会关注玩家、修改账号资料或执行游戏内操作。
- 安装前可直接审阅全部源码；仓库不包含远程加载的扩展代码。

## 已知限制

- 搜索依赖当前登录状态、吗哩吗哩网页结构和公开网页接口；其中任一项变化都可能导致暂时不可用。
- 为控制请求量，自动发现最多使用当前最高优先的 12 个具体因子；所有已选因子仍会参与最终评分。
- 当前对单个好友种马排名；角色条件用于限定好友种马本体，尚未计算自有种马与七角色组合相性。
- 结果质量取决于接口当前可返回的数据、搜索深度和好友池，并不保证找到全服最优解。

## 开发与测试

本项目没有构建步骤。修改源码后，在仓库根目录运行：

```powershell
node --test
node --check ranking.js
node --check page-bridge.js
node --check content.js
```

也可以直接在浏览器中打开 `tests/harness.html` 做静态界面检查。修改扩展后，需要在扩展管理页点击“重新加载”，再刷新吗哩吗哩页面。

## 项目结构

| 路径 | 作用 |
| --- | --- |
| `manifest.json` | Manifest V3 权限、站点范围与脚本入口 |
| `page-bridge.js` | 在页面上下文中调用官方网页接口 |
| `ranking.js` | 查询规划、因子整理与评分排序 |
| `content.js` | 面板 UI、交互、偏好存储与搜索流程 |
| `tests/` | Node.js 单元测试与浏览器静态检查页 |
| `reverse-notes/` | 接口字段和行为的复核记录 |
