项目维护工具

Umamusume Seed Publisher

为“闪耀优俊少女 · 种马搜索器”浏览器扩展提供商店更新发布。

这个工具做什么

这是项目维护者使用的自动发布工具。维护者授权后，GitHub Actions 通过 Chrome Web Store API 查询现有扩展的状态、上传经过校验的版本，并提交商店审核。它不提供游戏账号登录服务，普通扩展用户无需授权此工具。

Google 授权用途

仅请求 Chrome Web Store 管理权限（https://www.googleapis.com/auth/chromewebstore），用于维护授权账号拥有的扩展。本项目的发布工作流固定操作现有扩展 ID，不读取 Gmail、通讯录、Google Drive 或浏览器 Cookie。
