This is an unofficial helper for the Simplified Chinese version of Umamusume. It adds a sidebar to https://game.bilibili.com/tool/pd . Open that page, click the extension's on-page launcher, choose characters and factors, then search and inspect ranked friend candidates. The third-party toolbox requires a valid Bilibili login for live searches; the extension does not bypass login or provide account credentials. Manual factor selection and text recognition run locally after the toolbox catalog loads. Gold skills map to lower white factors using bundled data. Only storage permission and the existing toolbox/API host access are used. No remote executable code is downloaded. Reviewers who cannot access the third-party service should contact the developer through the support details in the store listing.

Version 0.19.0 adds two tabs within the same panel: seed search and support skill lookup. Support skill lookup works without login using a bundled Simplified Chinese snapshot; choose a skill, switch gold/lower-white results, and open card details. Images load from the original hdslb image service. No new extension permissions are requested.
