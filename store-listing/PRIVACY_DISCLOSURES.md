# 商店隐私与权限填写内容

以下内容与版本 0.7.0 的实际代码一致，可直接用于 Chrome Web Store 和 Microsoft Edge Partner Center。

## 单一用途

在吗哩吗哩工具箱页面中，根据用户选择的角色、因子、最低星级和优先级读取并排序好友种马候选。

## 权限理由

### storage

仅在用户设备上保存角色选择、因子及最低星级、颜色和 P 级顺序、搜索深度与过滤开关，以便下次打开时恢复设置。不用于跟踪或广告。

### https://game.bilibili.com/*

扩展只在 `https://game.bilibili.com/tool/pd*` 的吗哩吗哩工具箱页面注入用户界面，并通过页面上下文完成用户主动触发的查询。宽于具体路径的主机权限用于匹配该站点的页面脚本及浏览器权限模型，内容脚本实际匹配范围仍限制在 `/tool/pd*`。

### https://api.game.bilibili.com/*

用于在用户主动打开目录或搜索时，通过 HTTPS 读取因子目录、角色目录和好友种马结果。请求复用浏览器管理的现有 B 站登录会话；扩展不读取、保存、显示或导出 Cookie。

## 远程代码

否。全部可执行 JavaScript 都包含在扩展 ZIP 内；运行时只获取 JSON 数据，不下载或执行远程脚本、WASM 或字符串代码。

## 数据声明建议

- 按 Chrome 对“处理”的定义勾选：`身份验证信息`、`网站内容`、`用户活动`。身份验证信息仅指浏览器在 HTTPS 请求中向 B 站携带现有会话，扩展不读取或保存 Cookie；网站内容包括因子、角色、好友候选和好友 ID；用户活动包括在扩展内选择并本地保存的搜索偏好。
- 不收集或传输上述数据给扩展开发者。
- 不出售数据，不用于广告、信用评估或与单一用途无关的用途。
- 上述勾选采用保守披露，因为 Chrome 明确要求本地处理或存储也要披露。
- 扩展会在用户主动搜索时处理 B 站返回的角色、因子、好友候选和好友 ID，并仅在当前页面显示；这些内容不会发送给开发者。
- 扩展依赖浏览器随请求携带现有登录会话，但不直接访问 Cookie API，不保存认证信息。

如果后台问题的措辞发生变化，应优先选择最保守且与上述行为一致的答案，不要为了减少勾选项否认本地处理或第一方 API 传输。

## Limited Use 认证

所有数据仅用于提供扩展公开说明的单一用户可见功能；不出售，不用于个性化广告、再营销、信用评估或与功能无关的用途，不允许人工读取，并且只通过 HTTPS 传输。对应公开说明位于隐私政策的 “Chrome Web Store Limited Use” 一节。
